## 开始前

- 两人各使用一个独立 Steam 账号和合法的 Steam 正式分支原版游戏。当前服务器测试来源固定为 build `25921972`、游戏版本 `1.5.0`；若 Steam 已发布更新，由维护者更新或调整服务器以匹配客户端，再开始测试。
- 在游戏设置中关闭 crossplay（跨平台联机）。
- 从 Steam 正常启动原版游戏，不使用之前提供的 Mod 客户端副本、测试包或启动脚本。
- 优先使用有线网络。先测同一局域网（LAN），通过后再测公网（WAN）；公网测试至少一人使用另一条外网，例如手机热点。同一家庭内连接公网地址可能只测到回流。

## 连接服务器

进入游戏主菜单，按 `Ctrl + Alt + 反引号键` 打开控制台；反引号键通常在 Esc 下方。依次输入以下两行，将占位符替换为私人连接说明中的信息：

同一软路由局域网内使用 LAN 地址和游戏端口 `27015`：

```text
cl_password "SERVER_PASSWORD";
connect "LAN_HOST:27015";
```

朋友在其他网络上通过已部署的 FRP 云入口连接，游戏端口为 **`28015`**：

```text
cl_password "SERVER_PASSWORD";
connect "PUBLIC_HOST:28015";
```

`SERVER_PASSWORD`、`LAN_HOST` 和 `PUBLIC_HOST` 均为占位符，使用私人连接说明中的实际值。公网查询端口为 UDP `28016`，Steam 端口为 UDP `28017`，不能作为游戏连接端口。云主机的 `27015` 已由其他游戏使用，本项目不能连接或占用它。

FRP 公网 A2S 查询已连续3次成功，且已验证单个原版客户端入大厅、认证及服务端启动首关；查询结果中的 `gamePort` 仍公布内网的 `27015`。本轮请直接使用上述控制台 `connect "PUBLIC_HOST:28015"`，不要依赖 Steam 服务器浏览器自动选择连接端口。这些结果不能代替图形客户端实际操作、双人及长期同步验收。

若无法连接，记录尝试时间、错误文字和所用网络，发给维护者。出现 Mod 或 version mismatch（版本不匹配）时，由维护者修复服务端的兼容性；不要求玩家安装客户端补丁、Mod 或忽略版本检查的插件。

## 两个人一起做这些检查

1. 确认两人都进大厅、都能选角色和准备，再一起开局。
2. 双方分别移动、冲刺、使用技能、拾取物品、攻击并击杀怪物。互相确认伤害、血量、怪物位置和物品归属是否一致。
3. 连续完成至少5次换图，留意传送后是否有人卡住、角色消失或看到不同状态。随后安排一次死亡与观战，继续检查状态同步。
4. 在一次测试中，由一名玩家退出再重新连接，记录是否成功、角色与物品是否恢复；不要预先假定游戏支持原样恢复。重连后再测试换图与技能。
5. 完成一次对局结束/结算，核对两人是否都能到达结算界面并正常返回。LAN完成后，按同样步骤再做一轮WAN对照。
6. 基础双人测试通过后，安排5–6个独立 Steam 账号同时连接，确认第5、第6人能够进大厅、选角色和进入关卡；单独记录死亡与复活过程。不要把配置显示6人或 Mod 加载成功当作这两项功能已通过。

## 发现瞬移或卡顿时

记录准确时间（北京时间）、所在关卡、进入对局多久、当时做了什么，以及只有一人异常还是两人同时异常。尽量让两人各保存一段录像或截图，展示同一时刻各自看到的角色和怪物位置；同时记下是否正在下载、使用Wi-Fi或中转连接。

退出本轮后保留双方原版游戏日志，交给维护者与服务端同时间日志对照。附上 Steam 游戏版本、LAN 或 WAN、人数和上述步骤结果；发出日志前检查并遮去密码等私人信息。不要只报告“延迟高”，具体时间和双方视角最有助于定位。

# 和朋友一起测试

**本轮V7诊断服已完成单客户端首关复测，现保留在空大厅，供下列双人测试使用；正式稳定性验收尚未通过。** 候选 Mod 和配置仍在调整；能进大厅或看到服务器在线，不代表本轮已通过游戏测试。

2026-10-18 已准备双人诊断候选包 `output/Rains-client-test-25921972-v7.2.zip`（约26MB）。它只包含固定Mod、启动前校验和对应开源源码/原始包，不含游戏本体、账号凭据或连接密码。私人连接信息另存 `output/双人测试连接说明.txt`，不要公开发布。本机也已准备独立图形测试副本 `output/player-client-25921972-v7.2`，其启动前校验通过，图形显示与操作仍待人工确认。

先将合法原版Steam游戏复制到单独的新目录，再把ZIP内容解压到副本的exe旁。在该目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Launch-TestClient.ps1` 启动图形客户端；可先加 `-CheckOnly` 只验证当前游戏、Unity、FPTS与原生配置。首次启动会重新生成MMHOOK。不要混入旧Mod，不要覆盖原玩家安装目录。此图形客户端候选还需要人工确认正常显示和操作。

## 开始前

- 两人均使用 Steam 正式分支，当前测试来源为 build `25921972`、游戏版本 `1.5.0`。暂停自动更新带来的版本漂移；若 Steam 有新更新，先由维护者确认本轮采用哪个版本。
- 在游戏设置中关闭 crossplay（跨平台联机）。
- 使用维护者为**本轮**提供的完全相同 Mod 版本和配置；不要沿用旧候选，也不要额外加插件。首次无 Mod 对照测试则两人都用维护者确认的无 Mod 配置。
- 优先使用有线网络。先测同一局域网（LAN），通过后再测公网（WAN）；公网测试至少一人使用另一条外网，例如手机热点。同一家庭内连接公网地址可能只测到回流。

## 连接服务器

维护者确认就绪后会提供本轮地址、端口和密码。进入游戏主菜单，按 `Ctrl + Alt + 反引号键` 打开控制台；反引号键通常在 Esc 下方。依次输入以下两行，将尖括号内容替换为维护者提供的信息，输入时删除尖括号：

```text
cl_password "<服务器密码>";
connect "<服务器地址>:<游戏端口>";
```

若无法连接，记录尝试时间、错误文字和所用网络，发给维护者。不要连续反复重连或自行安装忽略版本检查的插件。

## 两个人一起做这些检查

1. 确认两人都进大厅、都能选角色和准备，再一起开局。
2. 双方分别移动、冲刺、使用技能、拾取物品、攻击并击杀怪物。互相确认伤害、血量、怪物位置和物品归属是否一致。
3. 连续完成至少5次换图，留意传送后是否有人卡住、角色消失或看到不同状态。随后安排一次死亡与观战，继续检查状态同步。
4. 在一次测试中，由一名玩家退出再重新连接，记录是否成功、角色与物品是否恢复；不要预先假定游戏支持原样恢复。重连后再测试换图与技能。
5. 完成一次对局结束/结算，核对两人是否都能到达结算界面并正常返回。LAN完成后，按同样步骤再做一轮WAN对照。

## 发现瞬移或卡顿时

记录准确时间（北京时间）、所在关卡、进入对局多久、当时做了什么，以及只有一人异常还是两人同时异常。尽量让两人各保存一段录像或截图，展示同一时刻各自看到的角色和怪物位置；同时记下是否正在下载、使用Wi-Fi或中转连接。

退出本轮后保留双方 `BepInEx/LogOutput.log`（无 Mod 时保留游戏日志），交给维护者与服务端同时间日志对照。附上本轮 Mod/配置标识、LAN或WAN、人数和上述步骤结果即可；发出日志前检查并遮去密码等私人信息。不要只报告“延迟高”，具体时间和双方视角最有助于定位。
